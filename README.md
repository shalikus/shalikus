## Currently building

### `shemaforge`

**XSD → TypeScript**

A developer tool for generating strongly typed TypeScript interfaces from XSD
schemas.

The goal is simple: make working with XML schemas predictable, type-safe, and
convenient for TypeScript projects.

## Featured project

> **shemaforge**  
> XSD schemas in. TypeScript interfaces out.

The project is being developed as a proper open-source developer tool rather
than a one-off script.

The long-term goal is to combine schema parsing, TypeScript code generation, and
XML/XSD validation into a reliable toolkit for TypeScript developers working
with structured XML documents.
